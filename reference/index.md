# Package index

## Model fitting

Bayesian meta-analytic mixture models, with and without selection models
for publication bias.

- [`re_mix()`](https://maxmaier42.github.io/metamix/reference/re_mix.md)
  : Random-Effects Meta-Analytic Mixture Model
- [`sel_mix()`](https://maxmaier42.github.io/metamix/reference/sel_mix.md)
  : Meta-Analytic Mixture Model with a Step-Function Selection Model
- [`sel_flexpb()`](https://maxmaier42.github.io/metamix/reference/sel_flexpb.md)
  : Meta-Analytic Mixture Model with Group-Specific Selection Models
